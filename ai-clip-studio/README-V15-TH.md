# AI Clip Studio V15 — ความยาว 1 นาที

- เลือก **60 วินาที** เป็นค่าเริ่มต้นในหน้าเว็บ (ยังเลือก 15/30 วินาทีได้ตามเดิม)
- ให้ Gemini เขียนบทพากย์โดยมุ่งเป้าการเล่าเรื่องประมาณ 1 นาที จากภาพจริงในต้นฉบับ
- ปรับความเร็วพากย์เล็กน้อยโดยรักษาระดับเสียงเดิม ไม่เรียก Gemini เพิ่มเพื่อแก้เวลา
- ปรับไฟล์ MP4 สุดท้ายเป็น 1,800 เฟรมที่ 30 FPS และตรวจสอบเวลาประมาณ 60.00 วินาที
- หลีกเลี่ยงภาพไม่เกี่ยวข้องหรือภาพนิ่งค้างยาว ๆ เพื่อยืดเวลา
- หากวิดีโอต้นฉบับสั้นกว่า 35 วินาทีหรือเสียงพากย์ผิดช่วงมาก ระบบแจ้งข้อจำกัดแทนการผลิตวิดีโอที่ผิดธรรมชาติ
- คง V14 จับภาพให้ตรงบทพากย์, ระบบ checkpoint, ซับไทย และเสียงต้นฉบับไว้

**หมายเหตุ** ยังไม่ได้ทดสอบการสร้างคลิปผ่าน Gemini API จริงบน Render แผน Free อาจมีข้อจำกัด CPU/โควตา
