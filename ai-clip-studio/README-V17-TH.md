# AI Clip Studio V17 — แก้ครบชุดและสงวนโควตา

- พบกรณีเสียงพากย์จริง 78.7 วินาที: แก้ให้ปรับ WAV เดิมด้วย FFmpeg เป็นคลิป 60 วินาที โดยไม่สั่ง Gemini สร้างเสียงซ้ำ
- จำกัดบทพากย์ให้อยู่ในช่วงเหมาะสมก่อนเรียก TTS และตัดออกเฉพาะประโยคที่มีช็อตภาพจริงรองรับเท่านั้น
- ถ้าข้อมูลไม่พอ จะหยุดก่อนเรียก TTS เพื่อไม่ให้เสียโควตาเสียงไปฟรี
- เก็บผลวิเคราะห์ดิบทันทีหลัง Gemini ตอบสำเร็จ และใช้ซ้ำเมื่อกดทำงานต่อ
- ไม่สั่ง Gemini ซ้ำอัตโนมัติเมื่อพบ 429 / 5xx / timeout
- รวมระบบภาพตรงกับคำพากย์ V14, ความยาว 60 วินาที V15 และแก้ช็อตสั้น V16
- ทดสอบด้วย Gemini จำลอง (ไม่ใช่บริการจริง) พร้อม FFmpeg สร้าง MP4 จริง 60 วินาที 1,800 เฟรม

ข้อจำกัด: ระยะเวลาพากย์ขึ้นกับ AI, ไม่สามารถรับประกันคลิปทุกไฟล์จะได้หนึ่งนาทีโดยไม่กระทบคุณภาพ และ Render Free อาจล้างไฟล์งานเมื่อรีสตาร์ต อย่า Deploy ขณะมีงานกำลังสร้างคลิป
