# AI Clip Studio V14 — Universal Visual Matching

- จับคู่ทุกประโยคพากย์กับช็อตในไฟล์ MP4 ที่อัปโหลดจริง โดยไม่มีรายการคำเฉพาะหัวข้อ
- Gemini ต้องส่งหลักฐานภาพ (`visual_matches`: id, score, evidence) ของแต่ละประโยค
- ระบบคัดช็อตที่ไม่แสดงหลักฐานหรือความมั่นใจต่ำกว่า 0.78 ออก **ก่อน** สังเคราะห์เสียง
- เมื่อภาพไม่พอ ระบบอาจต้องลดข้อความหรือหยุดงาน แทนการใช้ภาพที่ไม่เกี่ยวข้อง
- โมเดลยังประเมินภาพผิดได้; คะแนนเป็นความมั่นใจที่โมเดลรายงานเอง ไม่ใช่ความถูกต้องที่พิสูจน์แล้ว
- รองรับวิดีโอที่ผู้ใช้อัปโหลด; ไม่ดึงสต็อกหรือภาพใหม่จากอินเทอร์เน็ต
- ข้อจำกัดเดิมยังคงอยู่: การใช้ช็อตซ้ำเพื่อเติมช่วงเสียง (V12), ข้อจำกัด Render Free และการตรงของเวลาคำพูดยังเป็นการประมาณ
- ตั้ง Dockerfile path เป็น `ai-clip-studio/Dockerfile` สำหรับ repo root
