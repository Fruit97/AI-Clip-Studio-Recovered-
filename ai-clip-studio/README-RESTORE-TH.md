# AI Clip Studio — ชุดกู้โปรเจกต์หลังย้าย GitHub

เวอร์ชัน: V13-restored (ประกอบกลับจากซอร์สสำรอง V9 + โมดูล V11 + V12 และแพตช์จัดการ Gemini V13)

## ความสามารถ
- อัปโหลด MP4/MOV/WEBM/MKV แบบแบ่งชิ้น (สูงสุดตาม MAX_UPLOAD_MB, ค่าเริ่มต้น 1,024 MB)
- วิเคราะห์ proxy ความละเอียดต่ำจากไฟล์ต้นฉบับเพื่อลด RAM เมื่อรับวิดีโอ 1080p
- ตรวจจุดเปลี่ยนฉาก, AI จับคู่ความหมายของคำบรรยายกับภาพต้นฉบับ, ตัดต่อแบบช็อตสั้น
- ทำ MP4 แนวตั้ง 720 × 1280 ที่ 30 FPS, ซับ Noto Sans Thai ขาว-เหลือง, ผสมเสียงต้นฉบับได้
- จำสถานะงานและผลลัพธ์เฉพาะช่วงที่เซิร์ฟเวอร์ยังเก็บไฟล์ไว้ มีปุ่มทำงานต่อจาก checkpoint
- กรณี Gemini 429 หยุดทันที ไม่มี retry อัตโนมัติ; กรณี 503 จำกัดการลอง 3 ครั้ง; กรณี read timeout ไม่ยิงคำขอซ้ำ
- คลัง API Key แบบเข้ารหัส AES-GCM ในเบราว์เซอร์ (ต้องใช้ HTTPS)

## เริ่มรันด้วย Docker
`docker build -f ai-clip-studio/Dockerfile -t ai-clip-studio .`
`docker run --rm -p 10000:10000 -e PORT=10000 ai-clip-studio`

เปิด http://localhost:10000 หากรัน Docker บนคอมพิวเตอร์ตัวเอง; บน Render จะได้ HTTPS อัตโนมัติ

## ทดสอบภายในเครื่อง
ติดตั้ง Python 3.11+ และ FFmpeg, จากนั้น `cd ai-clip-studio && pip install -r requirements.txt pytest` และ `pytest -q test_v11.py test_v12.py test_v13_safety.py`

## การย้ายจาก GitHub ที่ถูกระงับ
ซอร์สนี้ไม่ได้พึ่ง repository เก่า. ต้องสร้าง repository ใหม่ในบัญชี GitHub ที่มีสิทธิ์ก่อน, อัปโหลดโค้ดในชุดนี้เป็นไฟล์แต่ละไฟล์ (ไม่ใช่อัปโหลด ZIP เป็นไฟล์เดียว), จึงจะ Deploy บน Render จาก Dockerfile ของ repo ใหม่ได้.

ตัว Render เดิมยังผูกกับ repo เก่า; ไม่มีการเปลี่ยนแปลง Render ในการกู้ไฟล์ชุดนี้.

## ข้อจำกัดที่สำคัญ
- งานยังต้องใช้ Gemini API Key ที่มีโควตา และระบบออนไลน์ ไม่ใช่ AI ออฟไลน์
- โควตา 429 ต้องรอ Google รีเซ็ตหรือจัดการแผนชำระเงิน ไม่ใช่บั๊กที่แก้ให้ใช้ฟรีไม่จำกัดได้
- Checkpoint และวิดีโอเก็บบนดิสก์เครื่องที่รัน (เช่น /tmp บน Render); เมื่อ Render Free รีสตาร์ตอาจหายทั้งหมด
- ข้อความที่ตรงกับภาพไม่ได้รับประกัน 100% เพราะขึ้นกับการวิเคราะห์ภาพของ Gemini และคุณภาพของต้นฉบับ
- หาก upload ขนาด 1 GB บน Render Free อาจพบข้อจำกัดของพื้นที่/หน่วยความจำ/timeout; อย่าอ้างว่ารองรับได้ครบทุกไฟล์
- ไม่มีการทดสอบ Google Gemini end-to-end ด้วย API Key จริง เนื่องจากไม่ใช้คีย์ของผู้ใช้โดยไม่ได้รับและไม่มีโควตาทดสอบ
- ชุดนี้ไม่ใช่การคัดลอก V13 ตรงจาก repo ที่ถูกระงับ เพราะยังเข้าถึงต้นทางเดิมไม่ได้ เป็นการกู้กลับจากข้อมูลสำรองที่มี
